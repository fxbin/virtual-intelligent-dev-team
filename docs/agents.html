8 Specialist Agents

按任务形状路由的专家角色

八位专家 Agent 覆盖了从代码到产品、从架构到发布的完整软件交付链路，每位都拥有独立的擅长领域、核心职责与可验证的交付证据要求。所有 Agent 在 references/agent-catalog.md（叙述版）与 references/routing-rules.json（机器可读版）中双重定义。

Optional Overlay

Stage Council

阶段专家团是八位 Agent 之上的可选 overlay：只在阶段专家会改变产物顺序时展开，不替代顶层 lead、workflow bundle 或 Team Engine Lite 验收。在 World-Class Product Architect 下按需展开，包含 product-discovery-council 与 prototype-design-council 两个阶段。

product-discovery-council
产品战略、PRD、用户研究、竞品分析、路线图定义
prototype-design-council
高保真原型、设计系统、可访问性审查、交互验证
